Mathematical Foundation

The Tank Filling Root-Finding Problem

Read Full Derivation →

To calculate the time $t^*$ at which the water volume $V(t)$ reaches the specified target level $V_{\text{target}}$, we formulate the continuous nonlinear objective function:

Continuous Root Equation
\[ f(t) = V(t) - V_{\text{target}} = 0 \quad \text{such that} \quad t \in [a, b], \; f(a) \cdot f(b) \le 0 \]

Bolzano's Bisection Method

Guarantees theoretical convergence by systematically halving the search interval $[a_k, b_k]$ around the target water level root with an error bound of $|b_k - a_k| / 2^k$.

Parameter Validation

Root Bracketing

Establishes initial bracket $[a_0, b_0]$ satisfying the sign test $f(a) \cdot f(b) \le 0$.

03

Iterative Halving

Calculates midpoint $c_k = \frac{a_k + b_k}{2}$ and shrinks the interval until $\epsilon_k < \text{tol}$.
